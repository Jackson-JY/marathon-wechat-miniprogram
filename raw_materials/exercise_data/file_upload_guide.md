# 文件上传导入功能指南

## 功能概述
文件上传导入功能允许用户直接上传运动数据文件，系统自动解析文件内容并将数据导入到数据库中。这是一个高效的数据导入方式，特别适合处理大量运动记录数据。

## 支持的文件格式

### 1. JSON 文件 (.json)
- **Garmin JSON**: 包含 `summarizedActivitiesExport` 字段的标准Garmin导出格式
- **标准JSON**: 运动记录数组格式
- **自定义JSON**: 其他符合规范的JSON格式

### 2. CSV 文件 (.csv)
- 逗号分隔值格式
- 第一行必须包含字段标题
- 支持UTF-8编码
- 自动识别字段映射

### 3. 文本文件 (.txt)
- 纯文本格式
- 自动识别内容格式
- 支持JSON和CSV内容
- 灵活的数据格式

## 功能特性

### 1. 智能文件识别
- 根据文件扩展名自动判断格式
- 内容格式自动识别
- 支持混合格式文件
- 错误格式友好提示

### 2. 自动解析功能
- 启用"自动解析"选项后，选择文件即自动处理
- 智能数据格式判断
- 自动字段映射和转换
- 实时解析进度反馈

### 3. 文件大小限制
- 最大支持10MB文件
- 文件大小实时显示
- 超出限制友好提示
- 建议使用UTF-8编码

### 4. 数据预览功能
- 文件内容前200字符预览
- 解析结果实时显示
- 数据条数统计
- 错误数据标记

## 使用流程

### 第一步：选择文件
1. 点击"点击选择文件"区域
2. 在文件选择器中选择支持的文件
3. 系统自动显示文件信息
4. 如果启用自动解析，自动开始处理

### 第二步：文件处理
1. 系统自动读取文件内容
2. 显示文件大小和类型信息
3. 上传进度实时显示
4. 文件内容预览展示

### 第三步：数据解析
1. 根据文件格式自动解析
2. 智能识别数据结构
3. 数据验证和错误检查
4. 解析结果统计显示

### 第四步：数据导入
1. 确认解析结果无误
2. 点击"插入数据"按钮
3. 批量导入到云数据库
4. 显示导入结果统计

## 操作选项

### 1. 数据验证
- **启用**: 自动检查数据完整性
- **检查项目**: 必填字段、数值范围、时间格式
- **错误处理**: 显示验证警告，用户选择是否继续

### 2. 覆盖重复数据
- **启用**: 自动处理重复记录
- **处理方式**: 根据activityId判断重复
- **注意事项**: 谨慎使用，避免数据丢失

### 3. 自动解析
- **启用**: 选择文件后自动开始处理
- **处理流程**: 读取文件 → 解析数据 → 显示结果
- **用户体验**: 减少手动操作步骤

```javascript

  filePath: filePath,
```

### 3. 格式识别
```javascript
// 根据文件扩展名判断格式
if (fileName.endsWith('.json')) {
  if (fileContent.includes('summarizedActivitiesExport')) {
    records = this.parseGarminData(fileContent);
  } else {
    records = this.parseStandardJson(fileContent);
  }
}
```

## 错误处理

### 1. 文件选择错误
- 文件类型不支持
- 文件大小超限
- 文件损坏或无法读取

### 2. 解析错误
- 格式不符合要求
- 编码问题
- 数据结构错误

### 3. 验证错误
- 必填字段缺失
- 数值范围异常
- 时间格式错误

### 4. 导入错误
- 网络连接问题
- 数据库操作失败
- 权限验证失败

## 常见问题

### Q1: 支持哪些文件格式？
A: 支持JSON、CSV、TXT格式，自动识别内容类型。

### Q2: 文件大小有限制吗？
A: 最大支持10MB，建议使用UTF-8编码。

### Q3: 如何启用自动解析？
A: 勾选"自动解析"选项，选择文件后自动开始处理。

### Q4: 数据验证失败怎么办？
A: 查看错误提示，修正数据格式，重新导入。

### Q5: 支持批量导入吗？
A: 支持，系统会自动分批处理大量数据。

文件上传导入功能为运动数据管理提供了高效便捷的数据导入方式。通过支持多种文件格式、智能解析验证、自动处理流程等特性，用户可以轻松地将各种来源的运动数据文件导入到系统中。
