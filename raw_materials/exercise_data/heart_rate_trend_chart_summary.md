# 心率趋势图功能总结

## 功能概述

心率趋势图是运动数据可视化页面的新增功能模块，专门用于展示用户的平均心率变化趋势。该图表以折线图的形式展示最近30天的心率数据，帮助用户了解自己的心率变化规律和运动强度趋势。

## 功能特点

### 1. 数据展示方式
- **图表类型**: 折线图（Line Chart）
- **X轴**: 日期（月/日格式，如3/15）
- **Y轴**: 平均心率（BPM，心跳/分钟）
- **数据范围**: 最近30天的运动记录
- **数据点**: 每天的平均心率值

### 2. 交互功能
- **数据点悬停**: 点击数据点显示详细信息
- **工具提示**: 显示具体日期和心率值
- **连接线**: 连接相邻数据点，展示趋势变化
- **网格线**: 提供心率值的参考基准

### 3. 数据处理逻辑
- **数据筛选**: 只处理有心率数据（avgHr）和开始时间（startTime）的记录
- **日期分组**: 按日期分组，计算每天的平均心率
- **数据排序**: 按时间顺序排列，确保趋势线的正确性
- **范围计算**: 动态计算Y轴范围，确保数据在图表中合理显示

## 数据展示逻辑

### 1. Y轴范围计算
```javascript
// 计算Y轴范围（心率范围：60-200 BPM）
const minHr = Math.min(...recentData.map(d => d.avgHr));
const maxHr = Math.max(...recentData.map(d => d.avgHr));
const yAxisMin = Math.max(60, minHr - 10);
const yAxisMax = Math.min(200, maxHr + 10);
```

**逻辑说明**:
- 最小心率不低于60 BPM（正常静息心率下限）
- 最大心率不超过200 BPM（运动心率上限）
- 在数据范围基础上增加10 BPM的缓冲空间

### 2. 数据点位置计算
```javascript
const xPosition = (index / (recentData.length - 1)) * 100;
const yPosition = ((day.avgHr - yAxisMin) / (yAxisMax - yAxisMin)) * 100;
```

**计算方式**:
- **X轴位置**: 基于数据点在数组中的索引位置
- **Y轴位置**: 基于心率值在Y轴范围内的相对位置

### 3. 连接线计算
```javascript
const width = Math.sqrt(Math.pow(x2 - x1, 2) + Math.pow(y2 - y1, 2));
const angle = Math.atan2(y2 - y1, x2 - x1) * 180 / Math.PI;
```

**计算方式**:
- **宽度**: 使用勾股定理计算两点间距离
- **角度**: 使用反正切函数计算连接线角度
