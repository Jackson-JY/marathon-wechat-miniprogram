# 运动数据可视化页面总结

## 页面概述

运动数据可视化页面是一个全新的功能模块，专门用于以图表和可视化的方式展示用户的运动数据。该页面提供了丰富的数据分析功能，帮助用户更好地理解自己的运动趋势和表现。

## 页面结构

### 1. 页面文件
- **WXML**: `miniprogram/pages/exerciseVisualization/index.wxml`
- **JavaScript**: `miniprogram/pages/exerciseVisualization/index.js`
- **样式**: `miniprogram/pages/exerciseVisualization/index.wxss`
- **配置**: `miniprogram/pages/exerciseVisualization/index.json`

### 2. 页面注册
已在 `miniprogram/app.json` 中注册新页面：
```json
"pages/exerciseVisualization/index"
```

## 主要功能模块

### 1. 数据概览卡片
- **总活动数**: 显示用户的总运动次数
- **总距离**: 累计运动距离（公里）
- **总时长**: 累计运动时间（小时）
- **总卡路里**: 累计消耗卡路里（千卡）

**设计特点**:
- 使用渐变背景色区分不同类型
- 响应式网格布局（2x2）
- 图标和数值的视觉层次

### 2. 活动类型分布（饼图）
- 按运动类型统计活动次数
- 支持的活动类型：跑步、骑行、游泳、徒步、健身、步行
- 动态计算扇形角度和颜色分配
- 包含图例显示具体数值

**技术实现**:
- CSS3 变换实现饼图扇形
- 动态计算角度和位置
- 响应式颜色主题

### 3. 月度趋势图（折线图）
- 显示最近6个月的活动趋势
- 包含网格线和坐标轴标签
- 数据点悬停显示详细信息
- 连接线展示趋势变化

**技术实现**:
- 绝对定位实现图表布局
- 动态计算数据点位置
- CSS变换实现连接线角度

### 4. 距离分布直方图
- 按距离区间统计活动分布
- 距离区间：0-5km、5-10km、10-21km、21-42km、42-100km、100km+
- 动态计算柱状图高度
- 悬停显示区间统计信息

**技术实现**:
- Flexbox布局实现柱状图
- 动态计算高度百分比
- 响应式柱状图宽度

### 5. 心率分析
- 心率区间分布统计
- 心率区间：恢复区、有氧区、燃脂区、耐力区、极限区
- 显示各区间的时长和百分比
- 颜色编码区分不同区间

**技术实现**:
- 进度条样式实现区间显示
- 动态计算百分比宽度
- 颜色主题区分区间类型

### 6. 个人最佳记录
- **最长距离**: 单次最长运动距离
- **最长时间**: 单次最长运动时间
- **最快配速**: 单次最快配速记录
- **最高卡路里**: 单次最高卡路里消耗

**设计特点**:
- 卡片式布局展示
- PB（Personal Best）徽章标识
- 相对时间显示（如"3天前"）

### 7. 数据筛选器
- **时间范围**: 最近7天、30天、3个月、6个月、1年、全部
- **活动类型**: 按运动类型筛选数据
- 重置和应用筛选功能

### 8. 数据导出
- 导出图表图片
- 导出数据报告
- 分享可视化结果

### 2. 图表渲染

### 3. 性能优化
- 数据懒加载

- 内存管理和清理

### 4. 用户体验
- 加载状态提示
- 空数据占位符
- 交互动画效果
- 触摸反馈

## 数据源和API

### 1. 云函数调用
```javascript

  name: 'exerciseDataFunctions',
  data: { type: 'getExerciseStats' }
});

// 获取详细记录
const recordsResult = await wx.cloud.callFunction({
  name: 'exerciseDataFunctions',
  data: { 
    type: 'queryExerciseRecords',
    page: 1,
    pageSize: 1000
  }
```
