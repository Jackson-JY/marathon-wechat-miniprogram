# 运动数据统计摘要

## 数据概览
- **数据来源**: Garmin设备导出
- **文件大小**: 约9.7MB
- **数据格式**: JSON
- **编码**: UTF-8
- **记录数量**: 大量运动记录（具体数量需要进一步分析）

## 数据字段统计

### 核心字段（必填）
- `activityId`: 活动唯一标识符
- `name`: 活动名称
- `activityType`: 活动类型
- `duration`: 持续时间
- `distance`: 距离

### 运动指标字段
- **速度相关**: `avgSpeed`, `maxSpeed`
- **心率相关**: `avgHr`, `maxHr`, `minHr`
- **功率相关**: `avgPower`, `maxPower`, `normPower`
- **步频相关**: `avgRunCadence`, `maxRunCadence`
- **步态相关**: `avgVerticalOscillation`, `avgGroundContactTime`, `avgStrideLength`

### 位置信息字段
- **坐标**: `startLatitude`, `startLongitude`
- **海拔**: `elevationGain`, `elevationLoss`

### 时间信息字段
- **时间戳**: `beginTimestamp`, `startTimeGmt`, `startTimeLocal`
- **时区**: `timeZoneId`

### 训练效果字段
- **有氧效果**: `aerobicTrainingEffect`
- **卡路里**: `calories`, `bmrCalories`

## 数据特点

### 1. 数据完整性
- 包含完整的运动轨迹信息
- 涵盖多种运动类型（跑步、骑行等）
- 提供详细的生理指标数据

### 2. 数据精度
- 时间精度：毫秒级时间戳
- 位置精度：GPS坐标
- 生理数据：心率、功率等专业指标

### 3. 数据应用价值
- 训练计划制定
- 运动表现分析
- 健康状态监测
- 社交分享功能

## 在马拉松伙伴项目中的应用场景

### 1. 训练计划模块
- 基于历史数据制定个性化训练计划
- 分析训练负荷和恢复需求
- 预测比赛成绩

### 2. 成绩记录模块
- 记录和追踪运动成绩
- 生成进步趋势图表
- 设置个人最佳记录

### 3. 跑友社区模块
- 分享运动成果
- 比较训练数据
- 组织团练活动

### 4. 数据同步功能
- 支持Garmin数据导入
- 实时数据同步
- 多设备数据整合

## 技术实现建议

### 1. 数据存储
- 使用云数据库存储用户运动记录
- 建立合适的索引提高查询效率
- 考虑数据分片和归档策略

### 2. 数据处理
- 实现数据解析和清洗逻辑
- 计算衍生指标（如配速、训练负荷等）
- 数据格式标准化

### 3. 数据展示
- 开发图表组件展示运动数据
- 支持多种数据可视化方式
- 移动端友好的数据展示

## 注意事项
- 数据量较大，需要考虑分页和懒加载
- 敏感数据需要适当的隐私保护
- 数据格式可能因Garmin版本而异
- 需要处理数据导入失败的情况
- 考虑数据备份和恢复策略
