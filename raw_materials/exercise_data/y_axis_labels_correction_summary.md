# Y轴标签修正总结

## 问题描述
用户反馈心率趋势图中Y轴上的数字展示是错误的，经过检查发现Y轴标签的生成逻辑与CSS网格线位置不匹配。

## 问题分析

### 1. 原始Y轴标签生成逻辑
```javascript
// 错误的逻辑：从0开始递增
const yLabels = [];
for (let i = 0; i <= 4; i++) {
  const labelValue = Math.round((yAxisMax / 4) * i);
  yLabels.push(labelValue);
}

// 结果：
// 标签0: (yAxisMax / 4) * 0 = 0
// 标签1: (yAxisMax / 4) * 1 = 25%最大心率
// 标签2: (yAxisMax / 4) * 2 = 50%最大心率
// 标签3: (yAxisMax / 4) * 3 = 75%最大心率
// 标签4: (yAxisMax / 4) * 4 = 100%最大心率
```

### 2. CSS网格线位置
```css
/* 网格线位置（使用top属性，数学坐标系统） */
.hr-trend-chart .grid-line:nth-child(1) { top: 0%; }    /* 对应Y轴标签 最大心率 */
.hr-trend-chart .grid-line:nth-child(2) { top: 25%; }   /* 对应Y轴标签 75%最大心率 */
.hr-trend-chart .grid-line:nth-child(3) { top: 50%; }   /* 对应Y轴标签 50%最大心率 */
.hr-trend-chart .grid-line:nth-child(4) { top: 75%; }   /* 对应Y轴标签 25%最大心率 */
.hr-trend-chart .grid-line:nth-child(5) { top: 100%; }  /* 对应Y轴标签 0 BPM */
```

### 3. 不匹配问题
- **标签顺序**: 从0递增到最大心率
- **网格线位置**: 从最大心率递减到0
- **结果**: Y轴标签与网格线位置完全不对应

## 修正方案

### 修正后的Y轴标签生成逻辑
```javascript
// 正确的逻辑：从最大心率开始递减到0
const yLabels = [];
for (let i = 0; i <= 4; i++) {
  // 从最大心率开始，递减到0
  const labelValue = Math.round(yAxisMax - (yAxisMax / 4) * i);
  yLabels.push(labelValue);
}

// 结果：
// 标签0: yAxisMax - (yAxisMax / 4) * 0 = 最大心率
// 标签1: yAxisMax - (yAxisMax / 4) * 1 = 75%最大心率
// 标签2: yAxisMax - (yAxisMax / 4) * 2 = 50%最大心率
// 标签3: yAxisMax - (yAxisMax / 4) * 3 = 25%最大心率
// 标签4: yAxisMax - (yAxisMax / 4) * 4 = 0
```

## 修正效果对比

### 修正前
- **Y轴标签**: 0, 25%最大心率, 50%最大心率, 75%最大心率, 最大心率
- **网格线位置**: 顶部(最大心率), 25%(75%最大心率), 50%(50%最大心率), 75%(25%最大心率), 底部(0)
- **问题**: 标签与网格线位置完全不匹配

### 修正后
- **Y轴标签**: 最大心率, 75%最大心率, 50%最大心率, 25%最大心率, 0
- **网格线位置**: 顶部(最大心率), 25%(75%最大心率), 50%(50%最大心率), 75%(25%最大心率), 底部(0)
- **结果**: 标签与网格线位置完美对应

## 技术要点

### 1. 数学坐标系统的标签顺序
- **顶部**: 最大心率值
- **中间**: 按比例递减的心率值
- **底部**: 0 BPM

### 2. 标签计算公式
```javascript
// 通用公式：从最大值递减到最小值
const labelValue = maxValue - (maxValue / (labelCount - 1)) * index;

// 具体应用：
const labelValue = yAxisMax - (yAxisMax / 4) * i;
```

### 3. 网格线与标签的对应关系
```
网格线位置    Y轴标签值
top: 0%     最大心率
top: 25%    75%最大心率
top: 50%    50%最大心率
top: 75%    25%最大心率
top: 100%   0 BPM
```

### 预期结果
- Y轴标签从顶部到底部正确显示
- 标签值与网格线位置完美对应
- 数据点位置与Y轴标签一致
- 整体视觉效果清晰准确

## 总结

通过修正Y轴标签的生成逻辑，成功解决了以下问题：

1. **标签顺序正确**: 从最大心率递减到0，符合数学坐标系统
2. **位置对应准确**: Y轴标签与CSS网格线位置完美匹配
3. **视觉效果一致**: 数据点、网格线、标签三者位置协调
4. **用户体验提升**: Y轴数值显示清晰准确，便于数据解读

**关键点**: 在实现数学坐标系统时，不仅要考虑数据点的位置计算，还要确保辅助元素（如Y轴标签、网格线）的位置与坐标系统保持一致。
