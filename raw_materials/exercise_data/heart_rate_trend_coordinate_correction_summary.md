## 坐标系统原理澄清

### CSS定位属性 vs 数学坐标系统
- **CSS的bottom属性**: `bottom: 0%` 表示在容器底部，`bottom: 100%` 表示在容器顶部
- **数学坐标系统**: Y轴向上为正方向，原点在左下角
- **关键理解**: 在CSS中，`bottom` 属性天然支持数学坐标系统！

### 正确的对应关系
```
CSS bottom值    数学Y坐标    心率值
0%             0           0 BPM
25%            0.25        25%最大心率
50%            0.5         50%最大心率
75%            0.75        75%最大心率
100%           1.0         最大心率
```
