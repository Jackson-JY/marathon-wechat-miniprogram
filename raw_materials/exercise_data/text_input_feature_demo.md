# 文本数据输入功能演示

## 功能概述
文本数据输入功能允许用户通过直接输入或粘贴文本的方式，将各种格式的运动数据导入到系统中。这是一个强大的数据导入工具，支持多种数据格式，并提供实时的数据验证和预览功能。

## 新增功能特性

### 1. 多格式数据支持
- **Garmin JSON**: 支持Garmin设备导出的标准格式
- **标准JSON**: 支持通用的运动记录JSON格式
- **CSV格式**: 支持逗号分隔值格式
- **自定义格式**: 自动识别数据格式类型

### 2. 智能数据解析
- 自动识别数据结构和格式
- 智能字段映射和转换
- 支持多种时间格式
- 自动标准化活动类型

### 3. 实时数据预览
- 解析结果实时显示
- 数据条数统计
- 前3条记录详细预览
- 超出部分提示信息

### 4. 数据验证功能
- 字段完整性检查
- 数值范围验证
- 时间格式验证
- 错误提示和建议

### 5. 批量数据插入
- 支持大量数据一次性导入
- 自动分批处理
- 插入结果统计
- 错误处理和重试

## 使用流程演示

### 步骤1: 选择数据格式
1. 点击"数据格式"下拉选择器
2. 根据数据来源选择相应格式
3. 系统会记住用户的选择偏好

### 步骤2: 输入或粘贴数据
1. 在文本框中直接输入数据
2. 从其他应用复制粘贴数据
3. 支持大段文本（最多10000字符）
4. 实时显示字符计数

### 步骤3: 解析验证数据
1. 点击"解析数据"按钮
2. 系统自动解析和验证
3. 显示解析结果预览
4. 检查验证错误提示

### 步骤4: 插入数据
1. 确认数据无误后点击"插入数据"
2. 系统批量插入到云数据库
3. 显示插入结果统计
4. 自动清空已插入的数据

## 数据格式示例

### Garmin JSON 示例
```json
{
  "summarizedActivitiesExport": [
    {
      "activityId": 20161383542,
      "name": "昌平区 跑步",
      "activityType": "running",
      "distance": 201509.99755859375,
      "duration": 757426.025390625,
      "avgHr": 153.0,
      "calories": 712.3033999999999
    }
  ]
}
```

### 标准JSON 示例
```json
[
  {
    "activityId": "run_001",
    "name": "晨跑5公里",
    "activityType": "running",
    "distance": 5000,
    "duration": 1800,
    "avgHr": 145,
    "calories": 350
  }
]
```

### CSV 示例
```csv
activityId,name,activityType,distance,duration,avgHr,calories
run_001,晨跑5公里,running,5000,1800,145,350
run_002,夜跑10公里,running,10000,3600,150,700
```
