# 心率趋势图数学坐标系统修改总结

## 概述
根据用户要求，将心率趋势图从CSS坐标系统改为数学坐标系统，使Y轴向上为正方向，更符合数学习惯和直观理解。

## 坐标系统对比

### CSS坐标系统（修改前）
- **Y轴方向**: 向下为正方向
- **原点位置**: 左上角 (0,0)
- **数据定位**: 使用 `top` 属性
- **特点**: 符合网页布局习惯，但不符合数学直觉

### 数学坐标系统（修改后）
- **Y轴方向**: 向上为正方向
- **原点位置**: 左下角 (0,0)
- **数据定位**: 使用 `bottom` 属性
- **特点**: 符合数学直觉，数据趋势更直观

## 具体修改内容

### 1. JavaScript数据处理修改

#### 数据点Y位置计算
```javascript
// 修改前：CSS坐标系统，Y轴向下
const yPosition = 100 - (day.avgHr / yAxisMax) * 100;

// 修改后：数学坐标系统，Y轴向上
const yPosition = (day.avgHr / yAxisMax) * 100;
```

#### 连接线角度计算
```javascript
// 修改前：考虑Y轴翻转
angle = Math.atan2(-deltaY, deltaX) * 180 / Math.PI;

// 修改后：标准数学角度计算
angle = Math.atan2(deltaY, deltaX) * 180 / Math.PI;
```

#### 垂直线角度
```javascript
// 修改前：翻转后的角度
angle = -90; // 向上（在翻转的Y轴中）
angle = 90;  // 向下（在翻转的Y轴中）

// 修改后：标准数学角度
angle = 90;  // 向上
angle = -90; // 向下
```

## 技术实现要点

### 1. 坐标转换原理
- **数学坐标**: (x, y) 其中 y 向上为正
- **CSS坐标**: (x, y) 其中 y 向下为正
- **转换公式**: CSS_y = 100 - 数学_y

### 2. 角度计算
- **Math.atan2(deltaY, deltaX)**: 计算两点间的角度
- **角度范围**: -180° 到 +180°
- **正角度**: 逆时针方向
- **负角度**: 顺时针方向

### 3. 数据定位策略
- **X轴**: 基于数据索引的百分比位置
- **Y轴**: 基于心率值在Y轴范围中的相对位置
- **定位方式**: 使用 `bottom` 属性，符合数学坐标系统
