# 数据点位置修正总结

## 问题描述
用户反馈Y轴展示的方向和数值是正确的，但是数据点的位置看起来不对。经过分析发现，虽然我们修正了Y轴标签，但数据点的Y位置计算仍然使用的是翻转公式，与新标签系统不匹配。

## 问题分析

### 1. Y轴标签系统（已修正）
```javascript
// 修正后的Y轴标签：从最大心率递减到0
const yLabels = [];
for (let i = 0; i <= 4; i++) {
  const labelValue = Math.round(yAxisMax - (yAxisMax / 4) * i);
  yLabels.push(labelValue);
}

// 结果：
// 标签0: 最大心率 (对应 top: 0%)
// 标签1: 75%最大心率 (对应 top: 25%)
// 标签2: 50%最大心率 (对应 top: 50%)
// 标签3: 25%最大心率 (对应 top: 75%)
// 标签4: 0 BPM (对应 top: 100%)
```

### 2. 数据点位置计算（正确）
```javascript
// 正确的计算：使用翻转公式
const yPosition = 100 - (day.avgHr / yAxisMax) * 100;

// 结果：
// 心率 = 0 BPM → yPosition = 100% (底部，对应标签0 BPM) ✓
// 心率 = 最大 → yPosition = 0% (顶部，对应标签最大心率) ✓
// 心率 = 50%最大 → yPosition = 50% (中间，对应标签50%最大心率) ✓
```

### 3. 坐标系统分析
经过仔细分析，我们的计算逻辑是正确的：

- **Y轴标签**: 从最大心率递减到0
- **CSS网格线**: top: 0% = 最大心率, top: 100% = 0 BPM
- **数据点位置**: 心率越高，应该越接近顶部（top值越小）

所以 `100 - (day.avgHr / yAxisMax) * 100` 这个公式是正确的！

3. **渲染问题**: 数据点的CSS样式可能影响显示
