# 马拉松伙伴 - 微信小程序

一个专为马拉松爱好者和跑步者设计的微信小程序，基于微信云开发构建。

## 🏃‍♂️ 主要功能

### 核心功能
- **训练计划**: 个性化跑步训练方案制定
- **赛事管理**: 马拉松赛事报名与追踪
- **成绩记录**: 详细跑步数据统计与分析
- **跑友社区**: 与跑友分享交流经验

### 快捷操作
- **开始跑步**: 快速启动跑步记录
- **报名赛事**: 便捷的马拉松赛事报名

### 数据统计
- 累计跑步次数
- 总里程统计
- 个人最佳成绩记录

## 🎨 设计特色

- **现代化UI**: 采用渐变色彩和卡片式设计
- **马拉松主题**: 专业的跑步应用界面
- **响应式布局**: 适配不同屏幕尺寸
- **流畅交互**: 丰富的动画效果和反馈

## 🛠️ 技术架构

- **前端**: 微信小程序原生开发
- **后端**: 微信云开发（CloudBase）
- **数据库**: 云数据库
- **存储**: 云存储
- **函数**: 云函数

## 🚀 快速开始

1. 克隆项目到本地
2. 使用微信开发者工具打开项目
3. 配置云开发环境ID
4. 部署云函数
5. 预览和调试
